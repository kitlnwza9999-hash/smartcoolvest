# 🦺 การจำลองวงจรและระบบไฟ SmartCool Vest บน Wokwi (ESP32-S3)

ไฟล์ในโฟลเดอร์นี้ออกแบบมาเพื่อให้คุณนำไปเปิดทดสอบระบบไฟ วงจรเซนเซอร์ และการทำงานของพัดลมบนเว็บไซต์ [Wokwi ESP32-S3](https://wokwi.com/projects/new/esp32-s3) ได้ทันที

---

## 📁 ไฟล์ที่มีให้ในโฟลเดอร์นี้

1. **`diagram.json`** : ผังวงจรฮาร์ดแวร์ ประกอบด้วย:
   - บอร์ด **ESP32-S3 DevKitC-1**
   - **หลอด LED สีน้ำเงิน + ตัวต้านทาน $220\,\Omega$** (GPIO 11): จำลองพัดลมตัว 70mm
   - **หลอด LED สีฟ้าคราม + ตัวต้านทาน $220\,\Omega$** (GPIO 12): จำลองพัดลมบ่า 40mm
   - **หลอด LED สีส้ม + ตัวต้านทาน $220\,\Omega$** (GPIO 13): จำลองพัดลมบอร์ด/แบตเตอรี่ 30mm
   - **เซนเซอร์ NTC Temperature Module** (GPIO 2): จำลองอุณหภูมิแบตเตอรี่ (เลื่อนปรับอุณหภูมิได้จริง)
   - **Potentiometer** (GPIO 1): จำลองระดับแรงดันและเปอร์เซ็นต์แบตเตอรี่ (SOC)
   - **เซนเซอร์ DHT22** (GPIO 4): จำลองอุณหภูมิและความชื้นอากาศรอบตัว
   - **ปุ่มกดสีแดง Pushbutton** (GPIO 10): สวิตช์หยุดฉุกเฉิน (EMERGENCY STOP)
2. **`sketch.ino`** : โค้ดภาษา C++ สำหรับรันบน Wokwi โดยเฉพาะ มีระบบ Soft-Start, คลื่น PWM 25 kHz, ระบบความปลอดภัย Multi-tier Safety และ Serial Interactive Dashboard
3. **`libraries.txt`** : รายชื่อไลบรารีที่ต้องติดตั้งในแท็บ Library Manager ของ Wokwi

## 🚀 ขั้นตอนการนำไปใส่ในเว็บ Wokwi (ทำตาม 4 ขั้นตอนนี้)

### ขั้นตอนที่ 1: วางผังวงจร (`diagram.json`)
1. ในหน้าเว็บ Wokwi ให้คลิกที่แท็บ **`diagram.json`** (อยู่ข้างๆ แท็บโค้ด)
2. ลบข้อความเดิมในช่องนั้นออกทั้งหมด
3. เปิดไฟล์ [`wokwi/diagram.json`](file:///c:/smartcoolvest-esp32/smartcoolvest/wokwi/diagram.json) คัดลอกโค้ดทั้งหมดแล้ววางลงไป
4. หน้าจอขวามือจะแสดงอุปกรณ์และสายไฟทั้งหมดเชื่อมต่อเข้ากับบอร์ด ESP32-S3 ทันที!

### ขั้นตอนที่ 2: เพิ่มไลบรารี (`libraries.txt`)
1. คลิกที่แท็บ **`Library Manager`** ใน Wokwi
2. พิมพ์ค้นหาและเพิ่มไลบรารี:
   ```text
   DHT sensor library for ESPx
   ```
   *(หรือเปิดแท็บ `libraries.txt` แล้ววางชื่อไลบรารีนี้ลงไป)*

### ขั้นตอนที่ 3: วางโค้ดโปรแกรม (`sketch.ino`)
1. กลับมาที่แท็บโค้ดหลัก (`sketch.ino`)
2. ลบโค้ดเริ่มต้นออกทั้งหมด
3. เปิดไฟล์ [`wokwi/sketch.ino`](file:///c:/smartcoolvest-esp32/smartcoolvest/wokwi/sketch.ino) คัดลอกโค้ดทั้งหมดแล้ววางลงไป

### ขั้นตอนที่ 4: กดปุ่ม Start Simulation (▶)
1. กดปุ่มวงกลมสีเขียว **Play (▶)** ที่ด้านบนเพื่อเริ่มจำลองการทำงาน
2. รอสักครู่จนกระทั่ง Serial Monitor ด้านล่างเริ่มแสดงผลแดชบอร์ด

## 🎮 วิธีทดสอบระบบไฟและฟังก์ชันต่าง ๆ ใน Wokwi

### 1. ทดสอบปรับความแรงพัดลม (PWM Dimming)
- ในช่องข้อความของ **Serial Monitor** ให้พิมพ์ตัวเลขแล้วกด Enter:
  - พิมพ์ `1` : ระดับ 1 (ลมตัว 20%, บ่า 20%) -> สังเกตหลอดไฟสีน้ำเงินและฟ้าจะติดสว่างหรี่ ๆ
  - พิมพ์ `3` : ระดับ 3 (ลมตัว 60%, บ่า 60%) -> หลอดไฟสว่างปานกลาง
  - พิมพ์ `5` : ระดับ 5 (ลมตัว 100%, บ่า 70%) -> หลอดไฟสว่างเต็มที่ (หลอดบ่าจะจำกัดที่ 70% ตามเกณฑ์ความปลอดภัย)
  - พิมพ์ `0` : ปิดพัดลมตัวและบ่า

### 2. ทดสอบระบบความปลอดภัยความร้อนแบตเตอรี่ (Battery Safety Trigger)
- **คลิกที่เซนเซอร์ NTC (ตัวสีส้ม/ดำทางซ้ายมือ):**
  - เลื่อนอุณหภูมิขึ้นไปที่ **$\ge 40^\circ\text{C}$**: หลอดไฟสีส้ม (พัดลมระบายบอร์ด 30mm) จะเร่งขึ้นเป็น 60%
  - เลื่อนอุณหภูมิขึ้นไปที่ **$\ge 50^\circ\text{C}$**: สังเกตหลอดไฟสีน้ำเงินและฟ้าจะ **หรี่ลงเหลือ 60% ทันที (Thermal Derating)** พร้อมขึ้นแจ้งเตือนบน Serial
  - เลื่อนอุณหภูมิขึ้นไปที่ **$\ge 60^\circ\text{C}$**: **ระบบจะตัดวงจรนิรภัยค้างทันที (Latch Cutoff)** พัดลมทุกตัวดับสนิท หลอดไฟทุกดวงดับ!
  - แม้จะเลื่อนอุณหภูมิลดลงมาแล้ว พัดลมก็จะไม่กลับมาหมุนจนกว่าจะพิมพ์คำสั่ง `reset` ใน Serial เพื่อความปลอดภัยสูงสุด!

### 3. ทดสอบการปรับระดับแบตเตอรี่ (SOC Slider)
- **คลิกหมุนตัวต้านทานปรับค่าได้ (Potentiometer สีน้ำเงินทางซ้าย):**
  - หมุนปรับค่าเพื่อดูเปอร์เซ็นต์ SOC บนแดชบอร์ดเปลี่ยนแปลงตั้งแต่ 0% ถึง 100%

### 4. ทดสอบปุ่มกดหยุดฉุกเฉิน (Hardware Pushbutton)
- คลิกที่ปุ่มกดสีแดง **`STOP`** ด้านล่างบอร์ด:
  - พัดลมทุกตัวจะดับทันที ระบบเข้าสู่สถานะ `EMERGENCY STOP`
